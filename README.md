## Associated publication

Jahan, A. A., Jeong, D. H., Youn, J. U., Lee, T. K., & Kim, M. (2025). **Multi-scale variance partitioning reveals hidden regional connectivity in groundwater contamination: Implications for drinking water security.** *Water Research X, 29*, 100409. https://doi.org/10.1016/j.wroa.2025.100409

The publication designates A. A. Jahan and D. H. Jeong as equal contributors.

## Overview

This study investigated groundwater contamination across **2,349 wells** in Chungcheongnam-do, South Korea, using groundwater observations from the **2017–2022** Safe Groundwater Project in Unsupplied Areas. It combined land-use characterization, spatial autocorrelation, geostatistical analysis, and assessment of local versus neighborhood-associated variability. The paper assessed 28 measured water-quality parameters, with a spatial emphasis on eight parameters that exceeded drinking-water standards in more than 1% of wells: **pH, NO₃–N, F, Al, As, Mn, Fe, and turbidity**.

### Selected published findings

- **16.1%** of wells exceeded the Korean standard for nitrate-nitrogen (NO₃–N).
- Nitrate exhibited an estimated **62 km correlation length**.
- Neighborhood-associated contributions to variability were reported as **38–40%** for nitrate and fluoride.
- The identified nitrate hotspots had substantially greater cropland coverage than non-hotspot areas (approximately **68% versus 33%**).

These values are reported findings from the paper, **not results regenerated by the code currently in this repository**.

## Methods reported in the publication

| Analysis | Published methodological specification |
|---|---|
| Land-use associations | Seven land-use categories measured within **1-km well buffers** using **QGIS 3.36.2**; Spearman's rank correlations |
| Spatial prediction | Ordinary kriging, empirical variograms, spherical/exponential model comparison by cross-validated RMSE, **500-m** raster resolution |
| Global spatial autocorrelation | Global Moran's I; **20 nearest neighbors**; row-standardized weights; `moran.test()` and **999** Monte Carlo replicates |
| Local clustering | Local Moran's I (LISA); **5 nearest neighbors**; row-standardized weights; **999** permutations; significant high-high, low-low, high-low and low-high classes |
| Correlation length | Fitted semivariogram, distance where modeled semivariance reaches **95% of sill** |
| Local/neighbor contributions | Z-score standardization; spatial lag of neighboring values; contribution as reported in manuscript |

**Important:** These are the methods *described in the published article*, not a claim that every archived script implements them verbatim. Refer to `docs/MANUSCRIPT_CODE_GAP_AUDIT.md` before reusing the code.

### Source code status

Files under `scripts/original/` are **preserved archival source files**. Files under `scripts/review_candidates/` have **not yet been attributed confidently** to a final published figure. Several original scripts contain exploratory code, local file paths, or method settings that differ from the manuscript; do not run the whole repository as one pipeline.

### Data availability

The publication states that datasets are available from the **corresponding author upon reasonable request**. Raw source data and supporting GIS layers have not been included here. To reproduce analyses, users will need authorized access to the datasets, administrative boundaries, and land-use layers, together with an appropriately documented R/QGIS environment.
